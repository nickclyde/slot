RetroAchievements

slot can earn RetroAchievements while you play. It needs two text files in the Config folder on your SD card: one for your Wi-Fi and one for your account.

  1. Tell slot about your Wi-Fi

    Create Config/wifi.txt:

    ssid = My Home Network
psk = my wifi password

    Leave out psk for an open network. If your network has no DHCP, add address = 192.168.1.50/24, gateway = 192.168.1.1 and dns = 192.168.1.1. Add ntp = on to set the clock from the internet once connected.

  2. Add your account

    Create Config/retroachievements.txt:

    username = YourName
password = your password

    The first time slot signs in, it swaps the password in this file for a login token, so your password does not stay on the card. If the token ever stops working, put a password line back in.

  3. Play

    slot signs in when it starts. Insert a cart and a banner shows the game and how many achievements you have. Each unlock pops up in the top left corner with its badge. On a game's first boot, the banner waits until the BIOS intro has played.

Softcore only

slot resumes from a save state every time you insert a cart, and lets you rewind and load Polaroids. RetroAchievements hardcore mode forbids all of those, so slot always plays in softcore.

Good to know

  • Link play takes over the Wi-Fi. slot drops off your network while a link session runs and reconnects afterwards. Unlocks earned in the meantime are sent once it is back online.
  • Unlocks earned offline are retried until the server confirms them.
  • Loading a Polaroid resets the progress of achievements that count over time, so a loaded state cannot unlock anything by itself.
  • If sign-in fails with a certificate error, check the clock: secure connections need the right date.
  • Delete Config/retroachievements.txt to turn achievements off, and Config/wifi.txt to keep the Wi-Fi off.
